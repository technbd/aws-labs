## AWS EC2:

Amazon **Elastic Compute Cloud (EC2)** is a core web service by **Amazon Web Services (AWS)** that lets you rent virtual servers—called instances to run computer applications in the cloud on a flexible, pay-as-you-go basis.

An **Amazon EC2 instance** is a virtual server in the AWS cloud. It lets you rent computer power by the second or hour, choose your own operating system, and scale capacity up or down instantly without buying physical hardware.



### Key Concepts and Features: 
- **Instances**: Virtual machines running on AWS hardware where you choose the CPU, memory, and operating system (like Linux or Windows).
- **Elasticity**: Scale capacity up or down instantly via APIs as your application traffic changes.
- **Security Groups**: Virtual firewalls that control inbound and outbound traffic to your servers.
- **Pricing Models**: Pay only for what you use through On-Demand, Reserved Instances, Savings Plans, or Spot Instances.



### Core Components:
- **AMI (Amazon Machine Image)**: The template or operating system image (like Linux or Windows) used to launch your server.
- **Instance Type**: The mix of CPU, memory, storage, and network capacity.
- **Security Groups**: A virtual firewall that controls inbound and outbound network traffic.



### Instance Tenancy: 

There are three tenancy options available:
- **Shared Tenancy (Default)**: This is the default mode. Instances run on physical hardware shared with other AWS accounts, separated securely by a hypervisor (ইনস্ট্যান্সগুলো অন্যান্য AWS অ্যাকাউন্টের সাথে শেয়ার করা ফিজিক্যাল হার্ডওয়্যারে চলে, যা একটি হাইপারভাইজর দ্বারা সুরক্ষিতভাবে পৃথক থাকে।). This is the most cost-effective and standard choice. 
- **Dedicated Instances**: Instances run on hardware dedicated solely to your AWS account, offering physical isolation from other customers (ইনস্ট্যান্সগুলো শুধুমাত্র আপনার AWS অ্যাকাউন্টের জন্য ডেডিকেটেড হার্ডওয়্যারে চলে, যা অন্যান্য গ্রাহকদের থেকে ফিজিক্যাল আইসোলেশন প্রদান করে।). You do not control exact server placement or see hardware details like physical sockets.
- **Dedicated Hosts**: You get a physical server fully dedicated to your use. This provides complete visibility into underlying hardware sockets, cores, and instance placement, making it ideal for strict compliance or Bring Your Own License (BYOL) needs.


There are three tenancy options:
| Tenancy     | Meaning                                                 | Typical use                              |
| ----------- | ------------------------------------------------------- | ---------------------------------------- |
| `default`   | Instance runs on shared AWS hardware                    | ✅ Normal/default                         |
| `dedicated` | Instance runs on hardware dedicated to your AWS account | Compliance/isolation                     |
| `host`      | Instance runs on a dedicated EC2 Dedicated Host         | Licensing/specific hardware requirements |



### Instance Types:
- **General Purpose**: Balanced CPU and memory for web servers and small databases.
- **Compute Optimized**: High-power CPUs for gaming servers and batch processing.
- **Memory Optimized**: High RAM for fast data processing and big analytics.
- **Storage Optimized**: Fast local disk access for heavy read/write databases.
- **Accelerated Computing**: Hardware GPUs for machine learning and graphics.



### Pricing Models:
- **On-Demand**: Pay as you go with no upfront cost.
- **Savings Plans**: Commit to 1 or 3 years for lower rates. Savings Plans are a flexible pricing model that offer low prices on EC2, Fargate and Lambda usage, in exchange for a commitment to a consistent amount of usage (measured in $/hour) for a 1 or 3 year term.
- **Reserved Instances**: Savings Plans are the easiest and most flexible way to save money on your AWS compute costs and offer lower prices (up to 72% off) just like Reserved Instances.
- **Spot Instances**: Bid on spare cloud capacity for deep discounts.
