## AWS EBS Volume: 

An **Amazon EBS (Elastic Block Store) volume** is a durable, block-level storage device that attaches to Amazon EC2 instances, functioning like a virtual hard drive. It provides reliable, low-latency performance for data storage, supports live configuration changes, and persists independently of the life of the instance.


### Core Characteristics:
- **Block Storage**: Provides raw, unformatted storage blocks to build file systems or run databases.
- **Zone-Locked**: Created inside a specific Availability Zone (AZ) and automatically replicated within that zone.
- **Persistence**: Data remains intact even if the attached EC2 instance stops or terminates.
- **Snapshots**: Supports point-in-time backups stored in Amazon S3 for disaster recovery or cloning.


### Volume Types: 
- **General Purpose SSD (gp3 / gp2)**: Balanced price and performance for boot volumes and standard applications.
- **Provisioned IOPS SSD (io2 / io1)**: High-performance storage built for heavy transactional and mission-critical databases. 
- **Throughput Optimized HDD (st1)**: Low-cost, throughput-heavy storage for large sequential datasets or log processing.
- **Cold HDD (sc1)**: The most inexpensive option meant strictly for infrequently accessed data.

## Create EBS volume using AWS Console:

Create an Amazon EBS volume to attach to any EC2 instance in the same Availability Zone.


### Steps: 

1. Open the [CloudWatch Console](https://us-east-1.console.aws.amazon.com/console/home?region=us-east-1) in the **us-east-1 (N. Virginia)** region.
    - Open the **EC2 Console**.
    - Select `Volumes` from the left menu under `Elastic Block Store` section, and click `Create volume`: 
        - Volume settings:
            - Volume type: `General Purpose SSD (gp3)`
            - Size (GiB): `20` 
            - IOPS: `3000`
            - Throughput (MiB/s): `125`
            - Availability Zone: `use1-az6 (us-east-1d)`
            - Snapshot ID - optional:
            - Encryption: [x] Encrypt this volume
        - Tags - optional:
        - Click `Create volume`

2. Attach the volume to instance:
    - Select EBS Volume - click `Actions` - click `Attach volume`
    - Availability Zone: `use1-az6 (us-east-1d)`
    - Select your running EC2 Instance: `web-server`
    - Device name: `/dev/sdb`
    - Click `Attach volume`


3. Login to EC2 instance and mount the volume by creating a file system:

_Check the disk on EC2:_
```
lsblk
```

4. Change/Modify:
    - Select EBS Volume - click `Actions` - `Modify Volume`: 
    - Volume Type: 
    - Size: `30`
    - click `Modify` - Yes.


5. If Delete Volume:
    - Select EBS Volume - click `Actions` - `Detach Volume` - Yes.
    - Select EBS Volume - click `Actions` - `Delete Volume` - Yes.

## Copy & Attach EBS volume to different Availability Zone:


Amazon EBS volumes directly to another Availability Zone (AZ)It is not possible to attach to an EC2 instance in , because EBS volumes are restricted to a specific AZ. To use the volume in another AZ, you **must take a snapshot**.


### Steps:
1. **Create snapshot**: Take a snapshot of the current EBS volume from the Amazon EC2 Console.
    - Select EBS Volume - click `Actions` - `Create snapshot`: 
        - Source volume ID: vol-0e3945ac148f672d5
        - Availability Zone: use1-az6 (us-east-1d)
        - Description: snapshot-01
    - Click `Create snapshot`

2. **Create a new volume**: Create a new EBS volume from the snapshot and select the target new Availability Zone.
    - Select `Snapshots` from the left menu under `Elastic Block Store` section: 
    - Select your snapshots - click `Actions` - `Create Volume from Snapshot`
        - Availability Zone: `use1-az1 (us-east-1a)` (select the target new Availability Zone)
    - click `Create Volume`

3. **Add to Instance**: Now add the newly created volume to your EC2 instance in the new AZ. Then Attach and mount the Volume.

## Copy & Attach EBS volume to another Region's:

attach an Amazon EBS volume to an EC2 instance in a different AWS region; instead, you must copy a snapshot of the volume to the target region and create a new volume from it.


### Steps to Migrate and Attach an EBS Volume Across Regions:

1. **Create snapshot**: Take a snapshot of the current EBS volume from the Amazon EC2 Console.
    - Select EBS Volume - click `Actions` - `Create snapshot`: 
        - Source volume ID: vol-0e3945ac148f672d5
        - Availability Zone: use1-az6 (us-east-1d)
        - Description: snapshot-01
    - Click `Create snapshot`

2. **Copy the Snapshot to another region**: 
    - Select `Snapshots` from the left menu under `Elastic Block Store` section: 
    - Select your snapshots - click `Actions` - `Copy snapshot`
        - Description: [Copied snap-0bafcf87a59c3eaee from `us-east-1`] snapshot-01 to `us-east-2`
        - Destination Region: `us-east-2` 
    - click `Copy snapshot`

3. **Create a new volume**: Go to the EC2 dashboard in the **target region** and create a new EBS volume from the copied snapshot.
    - Select `Snapshots` from the left menu under `Elastic Block Store` section: 
    - Select your snapshots - click `Actions` - `Create Volume from Snapshot`

3. **Add to Instance**: Attach or add the newly created EBS volume to the same Availability Zone of the specific instance (EC2 Instance) in the target region.
