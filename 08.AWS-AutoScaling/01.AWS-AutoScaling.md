## AWS Auto Scaling:

AWS Auto Scaling is a service that automatically adjusts the number of compute resources based on application demand.

_For EC2, the most common solution is EC2 Auto Scaling Group (ASG). It can:_
- Automatically launch EC2 instances when demand increases
- Automatically terminate instances when demand decreases
- Replace unhealthy instances
- Maintain a desired number of instances
- Distribute instances across Availability Zones
- Work with an **Application Load Balancer (ALB)** or **Network Load Balancer (NLB)**
- Perform scaling based on CPU utilization, request count, schedules, and other CloudWatch metrics



### Basic architecture:

```
                    Internet
                       |
                       v
              +----------------+
              |      ALB       |
              | Load Balancer  |
              +-------+--------+
                      |
          +-----------+-----------+
          |                       |
          v                       v
   +-------------+         +-------------+
   | EC2 Instance|         | EC2 Instance|
   |     AZ-A    |         |     AZ-B    |
   +-------------+         +-------------+
          \                       /
           \                     /
            +-------------------+
                    ASG
                     |
             CloudWatch Metrics
                     |
              Scaling Policies
```


### How It Works:
- **Auto Scaling Groups (ASG)**: Organizes resources like Amazon EC2 instances into logical groups to manage minimum, maximum, and desired capacities.
- **Scaling Policies**: Defines triggers for when to add (scale out) or remove (scale in) capacity based on real-time metrics.
- **Health Checks**: Automatically detects and replaces unhealthy instances to maintain high availability.



### Main components:
#### 1. Launch Template:  
A Launch Template defines how new EC2 instances should be created.

_It contains things such as:_
- AMI
- Instance type
- Key pair
- Security group
- IAM role
- EBS configuration
- User data
- Network settings


#### 2. Auto Scaling Group: 
The Auto Scaling Group controls the EC2 instances.

_Important settings:_
| Setting            |                Example |
| ------------------ | ---------------------: |
| Minimum capacity   |                      2 |
| Desired capacity   |                      2 |
| Maximum capacity   |                      5 |
| Availability Zones | us-east-1a, us-east-1b |
| Health check       |              EC2 / ELB |


#### 3. Scaling Policy : 
A scaling policy determines when the ASG should add or remove instances.

_Common types:_
- Dynamic Scaling: (maintaining a specific metric like 50% CPU and adjusting capacity based on alarm thresholds)
- Predictive scaling: 
- Scheduled actions :



#### 4. Health Checks: 
Auto Scaling can monitor instance health.

Suppose you have::
```
Instance 1 → Healthy
Instance 2 → Healthy
Instance 3 → Unhealthy
```

The ASG can terminate the unhealthy instance and launch a replacement.

## Auto Scaling setup using AWS Console: 

Setting up AWS EC2 Auto Scaling consists of two primary parts: creating a Launch Template to define what instances look like, and creating an Auto Scaling Group (ASG) to manage how they scale.



### Step 1: Create Security Group for ALB

1. Open the [CloudWatch Console](https://us-east-1.console.aws.amazon.com/console/home?region=us-east-1) in the **us-east-1 (N. Virginia)** region.
    - Open the **EC2 Console**.
    - Select `Security Groups` from the left menu under `Network & Security` section, and click `Create security group`: 
        - Security group name: `alb-sg`
        - Description: ALB security group
        - VPC: `(default)`
        - Inbound rules:
            - Type:       HTTP 
            - Protocol:   TCP
            - Port:       80 
            - Source:     Anywhere IPv4 (0.0.0.0/0)
        - Click `Create security group`

### Auto Scaling and Load Balancing:

These two services are often used together, but they do different jobs:

| Service                | Main responsibility                       |
| ---------------------- | ----------------------------------------- |
| **ALB/NLB**            | Distributes traffic                       |
| **Target Group**       | Registers and health-checks EC2 instances |
| **Auto Scaling Group** | Adds/removes EC2 instances                |
| **CloudWatch**         | Monitors metrics                          |
| **Launch Template**    | Defines new EC2 configuration             |
